Food Delivery Data Analytics Dashboard
Project Overview

This project presents an interactive Power BI dashboard developed to analyze food delivery transactions, food demand, payment preferences, customer membership types, and delivery performance.

The dashboard helps summarize key business metrics and identify trends in food ordering and transactions.

Dashboard Preview

Food Delivery Dashboard

Tools and Technologies
Microsoft Power BI
Power Query for data cleaning and transformation, 
DAX for calculated measures,
Data visualization and business intelligence
Key Performance Indicators (KPIs)
Total Quantity: Approximately 15K
Total Transactions: Approximately 2.75K
Average Quantity: 5.50

Dashboard Features
Monthly food quantity analysis
Food-wise quantity comparison
Transactions by food type and membership type
Delivery status analysis
Payment method comparison
Monthly transaction trends
Interactive filters for month, member type, payment method, and restaurant type
Key Insights
February records the highest monthly quantity among the months displayed.
Samosa has the highest quantity among the food items shown.
Main Course and Snack categories account for substantial transaction volumes.
UPI is the leading payment method in the displayed comparison.
Delivered transactions significantly exceed cancelled transactions

Project Objective

The objective is to demonstrate data analysis, KPI reporting, interactive dashboard design, and business insight generation using Power BI.
